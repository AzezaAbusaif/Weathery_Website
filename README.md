Weather App

A full-stack weather application built with Node.js, Express, and OpenWeatherMap API that displays current weather conditions and a 5-day forecast for any city.

---

 Features
Current Weather: View real-time temperature and weather conditions.
5-Day Forecast: Get weather predictions organized in clean, interactive daily cards.
Backend Integration: Uses Node.js and Express to securely fetch data from the OpenWeatherMap API.
Responsive Design:Styled with a clean, modern aesthetic inspired by modern mobile weather widgets.

---

 Technologies Used
Frontend: HTML5, CSS3, JavaScript 
Backend: Node.js, Express.js
API: OpenWeatherMap API (Current Weather & 5-Day Forecast endpoints)
